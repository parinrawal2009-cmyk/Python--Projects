# 🧮 Python Calculator

A simple calculator application made using Python and Tkinter.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Number buttons
- Clear functionality
- Graphical user interface (GUI)

## 🛠️ Technologies Used

- Python
- Tkinter

## ▶️ How to Run

1. Download `calculator.py`
2. Make sure Python is installed.
3. Open the file in VS Code.
4. Run the program.

## 📸 Project

This project is a beginner-friendly Python GUI calculator.
